title=Craft From Containers (Base Stock)
description=[b]Craft From Containers: craft with what's in your base[/b]
description=
description=Craft with items in nearby containers and anywhere in your Base Stock Counter base area, without hauling everything to your inventory first. Supports single-player, hosted multiplayer and dedicated servers. Requires Base Stock Counter.
description=
description=[b]Where items come from[/b]
description=Nearby: explored containers up to 5 squares away (configurable), on your floor and in the same building. It never reaches through a wall into another house.
description=Base area: while you stand in the Base Stock Counter area, explored containers anywhere in it, every floor.
description=
description=[b]Where it works[/b]
description=The crafting window and right-click crafts. Workstations like the forge, kiln, pottery wheel and loom, since they use the same window. Cooking: the right-click options that add an ingredient to a sandwich, salad or stew list ingredients from those containers too.
description=
description=[b]How a craft works[/b]
description=When the craft starts, the server checks every remote item and moves it to your inventory. The game's own craft runs. Tools and leftovers go back to the container they came from, so you keep the result. In a batch, tools stay with you until the last craft. If you cancel, what came over goes back.
description=
description=[b]Multiplayer[/b]
description=The client only asks. The server checks every item against its own state and moves it, so everyone sees the same thing. If a check fails, nothing moves and the craft is cancelled with a message. Two players going for the same item can't both get it.
description=
description=[b]Never used[/b]
description=Never-opened containers (using them would generate their loot), locked containers, safehouses you can't loot, corpses, vehicles, items on the floor and bags stored inside containers.
description=
description=[b]Sandbox options[/b]
description=Craft from the base area (on), nearby radius (5 squares), base container limit (256).
description=
description=[b]Installation and removal[/b]
description=Enable Base Stock Counter and this mod. Clients and the server need the same version. The mod saves nothing, so it's safe to remove: stop the save or server, disable it and start again. Items it moved are normal items wherever they ended up.
description=
description=Build 42.21.0. English and Brazilian Portuguese interface.
